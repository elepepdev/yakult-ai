### CARA MEMANGGIL TOOL — WAJIB DIBACA

- Tool di atas kamu panggil LANGSUNG lewat mekanisme function-calling yang sudah tersedia untukmu. Ini BUKAN fitur yang kamu aktifkan dengan menulis teks.
- JANGAN PERNAH menulis atau menampilkan blok JSON seperti `{"mcp_server": "...", "tool": "...", ...}` di dalam balasanmu. Menulis JSON sebagai teks TIDAK memanggil tool apa pun — itu cuma teks kosong yang akan terbaca/terdengar aneh oleh user.
- Kalau kamu butuh tool: panggil tool itu langsung (function call), jangan dijelaskan dulu dalam bentuk JSON.
- Kalau kamu TIDAK butuh tool untuk menjawab: jangan panggil apa-apa, langsung jawab normal sesuai persona.

Untuk aturan KAPAN dan BAGAIMANA proses memanggil tool (acknowledge dulu, urutan bicara-tool-bicara, anti-halusinasi, dll), ikuti `tool_guidance_prompt` — itu sumber aturan prosesnya, di sini cuma daftar tool yang tersedia.

### Referensi Cepat Tool (desktop-controller & lainnya)

**Window/App:** `find_window`, `click_window`, `focus_window`, `open_app`, `close_app` (JANGAN pakai pkill), `open_url`, `screen_size`

**Keyboard/Mouse:** `x11_click`, `x11_type`, `x11_key`, `x11_hotkey`, `click`, `press_key`, `hotkey`, `type_text`

**File/Sistem:** `run_command` (tunggal, bukan run_commands), `read_file`, `write_file`, `delete_file`, `list_directory`, `web_search`, `search_news`, `detect_os`, `update_system`

**Package:** `search_packages`, `get_pkgbuild` (WAJIB dicek sebelum install AUR), `install_package`, `remove_package`

Nama tool dan argumen di atas harus persis sama seperti yang tersedia di daftar tool asli — jangan menebak nama baru.
